# Zeldapro website starter

A responsive, static multi-page corporate website for Zeldapro.

## Pages
- Home
- About Zeldapro
- AI & Technology Services
- AI Solutions
- Industries
- Software Engineering
- Innovation & R&D
- Insights
- Careers
- Contact

## Preview locally
Open `index.html` in a browser, or run a local static server from this folder:
`python3 -m http.server 8000`
Then visit `http://localhost:8000`.

## Before production launch
1. Confirm legal company name, registered address, company details and approved brand logo.
2. The supplied Zeldapro logo is integrated into the site header and footer as a transparent horizontal lock-up; the original artwork is preserved in `assets/zeldapro-logo-original.png`. Confirm final brand usage and prepare a favicon from the approved emblem.
3. Connect the contact form to a verified business inbox or CRM. The current form is deliberately a front-end demo and does not transmit data.
4. Verify all product descriptions, especially Carevie, against current product capabilities.
5. Add approved leadership profiles, real case studies, client permissions, certifications and verified contact details. No client logos or unverified performance claims are included.
6. Configure hosting, HTTPS, DNS for `www.zeldapro.com`, redirects, analytics, cookie/privacy notices and a production sitemap/robots policy.
7. Have legal/privacy and security teams review website policies and any lead-capture implementation.

## Deployment
This is a static HTML/CSS/JS site and can be hosted on any standard static web host or web server. The domain is not configured by this project; DNS and hosting access are required to publish it.
